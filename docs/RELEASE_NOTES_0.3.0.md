# v0.3.0 更新说明

本版本精简了历次迭代累积的防御性代码，并修复 #24。

## 精简

- 调度器、实例服务、账号/Drive/工作台服务统一只对接真实的 `Repository`/`Store`，删除了为各种测试替身准备的 `hasattr`/`getattr` 探测、`TypeError` 回退调用和 MemoryStore 兼容分支。
- 删除吞掉或重复包装错误、但没有任何补救动作的 `try/except`；保留调用 Colab、Drive、子进程等外部系统时的真实错误处理。
- 删除不可能发生的分支、重复校验、无人使用的配置项和函数（如 `GPU_SPEC_ALLOWLIST`、规格字段猜测、`_now_iso` 等）。
- 认证、属主隔离、用户路径穿越检查、密钥处理等安全边界全部保留。

## #24 修复

- 运行时通过 `nvidia-smi` 上报实际 GPU，任务、实例、租约记录真实型号（`gpu_reported`），不再把申请的规格当作实际硬件。
- 自动分配在只有一个已授权 Colab 账号时，先绑定账号再走按账号 OAuth；缓存准备与 Drive 同步使用正确的计算号/Drive 号。
- Colab 分配失败区分 `NO_RUNTIMES`（容量不足）与其他错误，原始错误文本不外泄。
- 已释放或正在清理的租约不再被重新分配；清理重试后清除临时告警，保留原始失败原因。
- Windows 协调端改用跨平台文件锁；时间戳统一为带时区的 ISO 格式。
- 前端统一用 `gpuLabel` 显示“实际 GPU / 申请规格”。

以上修复参考并合入了 @CyrusAuyeung 在 #25 中的实现。
